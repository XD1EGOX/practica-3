# Etiquetas más usadas

## Texto

- `<h1>` a `<h6>`: títulos
- `<p>`: párrafo
- `<strong>`: texto en **negrita**
- `<em>`: texto en *cursiva*

## Listas, enlaces e imágenes

- `<ul>` y `<li>`: lista con puntos
- `<ol>` y `<li>`: lista numerada
- `<a>`: enlace
- `<img>`: imagen

```html
<a href="https://www.mkdocs.org/">MkDocs</a>
<img src="foto.png" alt="Una foto">
```

!!! info "Información"
    La imagen siempre lleva el atributo `alt`, que es el texto que sale si no carga.

!!! danger "Peligro"
    No hay que usar `<h1>` solo para hacer el texto más grande. Para eso está CSS.
